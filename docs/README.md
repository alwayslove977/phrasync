# Phrasync documentation

This directory contains repository documentation and public media, separate from runtime assets and user projects.

## Contents

- [`FEATURE_BACKLOG.md`](FEATURE_BACKLOG.md): future feature requests from alwayslove977 and impaler, with scope and acceptance checks; separate from release fixes.
- [`media/`](media/README.md): README screenshots, demo videos, and social preview assets.
- The project overview and user guide remain in the root [`README.md`](../README.md).
- Developer and architecture notes currently live in [`NOTES.md`](../NOTES.md).

User uploads, project saves, render jobs, and generated videos are not stored here. At runtime they live in the user's `~/.phrasync` directory.

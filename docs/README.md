- **中文用户入口**：项目概览、安装、系统要求、故障排查与已知限制见根目录
  [`README.md`](../README.md)（简体中文，仓库主页）；英文版为 [`README.en.md`](../README.en.md)。
- macOS 打包与兼容性修复记录：[`MACOS_FIXES.md`](MACOS_FIXES.md)（英文，开头有中文导读）

- 上游变更日志：[`../RELEASE_NOTES.md`](../RELEASE_NOTES.md)（英文）。
  本 fork 的 macOS 版本说明在 [Releases 页](https://github.com/alwayslove977/phrasync/releases)（中文优先）。
- 各版本验收与发布记录：`QA_v0.4.x.md`、`RELEASE_v0.4.x.md`（英文，工程记录）。

## English

This directory contains repository documentation and public media, separate from runtime assets and user projects.

### Contents

- [`media/`](media/README.md): README screenshots, demo videos, and social preview assets.
- The project overview and user guide live in the root [`README.md`](../README.md)
  (Simplified Chinese, the repository homepage); English: [`README.en.md`](../README.en.md).
- Developer and architecture notes currently live in [`NOTES.md`](../NOTES.md).

User uploads, project saves, render jobs, and generated videos are not stored here. At runtime they live in the user's `~/.phrasync` directory.
